# Portfolio — in your browser

This branch is the website at **https://onnipackalen.github.io/uebersicht-portfolio/**:
the Portfolio widget for Übersicht running in the browser, with live prices.
Visitors' holdings stay in their own browser.

It is built from the web app's source by `tools/build_pages.sh`; don't edit
these files by hand. The widget itself is on the `main` branch.
